# Лабораторная работа № 3 — «Доска публикаций»

**Тема:** Асинхронный JavaScript и REST API.  
**Технологии:** HTML, CSS, обычный JavaScript без фреймворков.  
**API:** https://jsonplaceholder.typicode.com/

## Состав архива

- `index.html` — интерфейс: кнопка загрузки, список, форма, сообщения.
- `style.css` — оформление и адаптация страницы к узкому экрану.
- `app.js` — GET, POST, валидация, события и изменение DOM; есть подробные комментарии.
- `README.md` — запуск, описание функций и сценарии проверки.

## Как запустить

1. Распаковать ZIP-архив
2. Открыть в браузере `index.html`
3. Убедиться, что есть интернет

## Что делает программа

**GET:** Кнопка «Загрузить публикации» отправляет запрос на `https://jsonplaceholder.typicode.com/posts?_limit=5`. После успешного ответа появляются пять карточек с заголовком и текстом. Во время загрузки показывается сообщение, кнопка заблокирована.

**POST:** В форме вводятся заголовок и текст. `trim()` удаляет пробелы по краям; если хотя бы одно поле пустое, запрос не отправляется. Иначе отправляется JSON `{ "title": "...", "body": "...", "userId": 1 }` на `https://jsonplaceholder.typicode.com/posts` методом POST с заголовком `Content-Type: application/json`. При успехе показываются заголовок, текст и ID из ответа (обычно HTTP 201 и ID 101).

**Ошибки:** При проблемах сети и ответах HTTP 404/500 отображается понятное сообщение, после чего кнопка снова доступна. Обработчики используют `try/catch/finally` и проверку `response.ok`. Страница не перезагружается; текст выводится через `textContent`.
